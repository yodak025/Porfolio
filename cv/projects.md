## Master Mind
**Algorithmic Logic Game**

Various implementations of the classic game to explore different architectural patterns. Implemented in Python (CLI), JavaScript (Web), and Swift (iOS) with a strong focus on separation of concerns and clean code.

## Pac-Man 3D
**WebGL Experiment**

A 3D interpretation of Pac-Man running natively in the browser. Built with Three.js without external game engines, featuring a custom collision detection system.

## Acoustic Engineering Project
**Environmental Study**

Comprehensive acoustic analysis of urban environments. Data collection using calibrated microphones followed by MATLAB processing for noise pollution mapping.
